# OpenDeepWiki

OpenDeepWiki 是一个开源的、AI 驱动的代码知识库。它分析来自 GitHub、GitLab、Gitee、Gitea 等平台的代码仓库，然后自动生成结构化文档、思维导图和知识图谱 — 一切只需几分钟。

基于 **.NET 10** 和 **Microsoft.Agents.AI**（多提供商 AI 编排框架），配合 **Next.js** 前端，OpenDeepWiki 架起了原始代码和人类可读文档之间的桥梁。

除 Git 仓库外，OpenDeepWiki 还支持上传 ZIP 压缩包和受允许根目录约束的本地目录导入，并通过后台 Worker 处理翻译、思维导图和 Graphify 图谱等衍生产物。

## 它能为你做什么

- **自动生成仓库文档**：README 摘要、项目概览、Wiki 目录与逐模块文档正文
- **多语言翻译**：一次生成，输出中、英、日、韩等 12 种语言
- **思维导图**：自动生成项目架构思维导图，支持 PNG/SVG 导出
- **AI 对话**：基于仓库知识的对话助手，可嵌入任意网站
- **MCP 服务**：把仓库知识暴露给 Claude、Cursor 等 MCP 客户端
- **企业级后台**：用户、角色、部门、API Key、AI 模型、技能包统一管理

## 工作原理

1. **导入** — 通过 Git URL 克隆、上传 ZIP 压缩包或导入受允许的本地目录
2. **扫描** — 递归扫描目录，尊重 `.gitignore`，按仓库规模自动选择扫描计划（深度/文件数预算）
3. **分析** — AI 生成目录结构、项目概览和每个模块的详细文档，后台 Worker 追加翻译、思维导图与 Graphify 产物
4. **服务** — 文档存储在数据库中，通过 Next.js 前端提供服务，支持全文搜索、MCP 和对话式 AI
