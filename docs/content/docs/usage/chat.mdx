# AI 对话

OpenDeepWiki 在仓库文档页内置了 AI 助手（悬浮球）。它以**本仓库的文档知识**为上下文回答问题，比直接问通用大模型更准确、更贴合你的代码。

## 启用前提

管理员需要先在后台完成两件事：

1. [模型管理](/docs/admin-guide/ai-providers)中有可用模型
2. [聊天助手](/docs/admin-guide/chat-assistant)中启用并勾选模型

未启用时仓库页面不会显示悬浮球。

## 使用方式

![仓库内 AI 对话](/images/repo-chat.png)

1. 进入任意仓库文档页，点击**右下角悬浮球**展开对话面板
2. 在输入框用自然语言提问，例如：
   - "这个项目的核心功能有哪些？"
   - "数据库迁移是怎么处理的？"
   - "我想新增一个 API 端点，应该改哪些文件？"
3. AI 基于文档知识流式回答，并给出依据

## 上下文感知

助手会自动携带**你当前正在阅读的文档**作为上下文：

- 正在读《Docker 部署》时问"这一步为什么必须改 JWT 密钥"，AI 知道"这一步"指什么
- 面板中可以手动切换关联的目录章节，把上下文指向其他文档

## 提问技巧

| 技巧 | 示例 |
| --- | --- |
| 先导航到相关章节再提问 | 读《架构设计》时问架构问题，回答更准 |
| 让 AI 定位代码 | "处理 ZIP 导入的代码在哪个模块？" |
| 让 AI 对比讲解 | "增量更新和全量生成的区别？" |
| 让 AI 给出操作步骤 | "如何把我的仓库接入 MCP？" |

## 全站搜索与对话

首页搜索框同样支持对话式提问：输入问题后系统会在公开仓库知识库中检索并给出跨仓库的回答，适合"我不确定在哪个仓库"的场景。

## 常见问题

**悬浮球不显示**
聊天助手未启用或未配置模型，联系管理员；或浏览器缓存了旧页面，强制刷新。

**回答到一半停了**
上游模型输出被截断或网络中断，重试即可；大问题建议拆小。

**回答与代码不符**
文档是快照，可能落后于代码。触发仓库[增量更新](/docs/advanced/incremental-updates)后重新提问。
