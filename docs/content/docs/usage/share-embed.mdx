# 分享与嵌入

除了站内阅读，OpenDeepWiki 提供两种把知识"带出去"的方式：**聊天分享链接**和**嵌入式聊天应用（Chat App）**。

## 聊天分享链接

把一段有价值的对话直接分享给同事：

1. 在仓库 AI 助手中完成一段对话
2. 点击面板中的分享按钮，生成 `/share/{shareId}` 链接
3. 对方打开即可看到这段对话的快照（问题、回答、引用的文档）

分享的是**快照**——之后知识库更新不影响已分享内容。

## 创建聊天应用（Chat App）

进入**工作区 → 我的应用**，点击**创建应用**：

![我的应用](/images/my-apps.png)

![创建应用表单](/images/app-create.png)

### 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 应用名称 | 是 | 如"产品文档助手" |
| 描述 | 否 | 简要描述应用用途 |
| 图标 URL | 否 | 可选，自定义悬浮球图标 |
| 域名校验 | 否 | 开关；"启用后仅允许指定域名访问"（防盗用） |
| 允许的域名 | 域名校验开启时显示 | 多行文本，**每行一个域名**，如 `example.com` |
| AI Provider | 是 | 下拉选择服务商（Endpoint 和 API Key 直接取自所选服务商，无需重复填写） |
| 默认模型 | 是 | 下拉选择该服务商下的模型 |
| 每分钟请求限制 | 否 | 数字；0 或留空表示不限制 |
| 启用应用 | 编辑时显示 | 开关，临时下线应用用 |

点**保存**完成创建。

## 获取嵌入代码

<Steps>

<Step>在"我的应用"卡片菜单进入**应用详情**。</Step>

<Step>复制页面提供的**嵌入脚本**（应用 ID 已自动带入），粘贴到目标网站 `</body>` 前：</Step>

```html
<script
  src="https://your-opendeepwiki.example/embed.js"
  data-app-id="你的应用ID"
  defer
>
</script>
```

</Steps>

页面右下角会出现聊天悬浮窗，访客提问即基于所选服务商/模型回答。

## 应用详情页

详情页除嵌入脚本外还提供：

- **应用 ID / 应用密钥**：密钥可显示/隐藏，支持**重新生成密钥**（旧密钥立即失效）
- **使用统计**：调用量等指标
- **提问记录**：每条提问的模型、来源域名等信息，用于审计与优化提示

## 嵌入与 MCP 的选择

| 需求 | 建议 |
| --- | --- |
| 给"人"看：网站访客自助问答 | 嵌入式 Chat App |
| 给"Agent"用：IDE/Agent 查询仓库知识 | [MCP 服务](/docs/mcp) |
| 分享单段对话 | 聊天分享链接 |
