# 思维导图

每个已生成的分支都会附带一张**项目架构思维导图**，把仓库的核心模块组织成一张可缩放的全景图，是快速建立全局认知的最佳入口。

## 打开方式

进入仓库文档页，点击左侧面板的**项目架构**，或直接访问 `/{owner}/{repo}/mindmap`：

![项目架构思维导图](/images/repo-mindmap.png)

## 视图与操作

| 功能 | 说明 |
| --- | --- |
| 思维导图 / 列表视图 | 图形视图直觉浏览；列表视图按层级精确定位 |
| 缩放 | 工具栏 +/- 按钮，或 `Ctrl/Cmd + 滚轮` |
| 重置 | 恢复 100% 与默认布局 |
| 导出 PNG / SVG | 下载当前导图，用于汇报、Wiki 引用 |

节点代表模块或子模块，分支颜色区分不同的一级主题。节点标题后若带有 `:path/to/file` 标注，表示该主题对应的源码位置。

## 导图是如何生成的

文档正文生成完成后，后台 Worker 会基于已生成的目录与文档内容生成一张架构导图，内容格式为 Markdown 标题层级（`#` / `##` / `###`），渲染为可视化思维导图。生成状态与正文生成一样可在后台[仓库管理](/docs/admin-guide/repositories)中查看。

导图与文档**同源**：仓库触发[增量更新](/docs/advanced/incremental-updates)后，导图也会随文档一起刷新。

<Callout type="info">
  导图状态为 Pending/Failed 时打开页面只会看到根节点。重新触发生成即可。
</Callout>

## 使用建议

- **新人入职**：先看导图建立全局认知，再顺着目录读文档
- **架构评审**：导出 SVG 贴进汇报材料，与团队对齐模块划分
- **定位代码**：借助节点上的源码标注，从主题直接跳到关键目录
