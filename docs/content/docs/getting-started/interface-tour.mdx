# 界面导览

登录后的站点由「前台」与「管理后台」两部分组成。本章走一遍前台核心页面；管理后台见[管理后台教程](/docs/admin-guide)。

## 首页（探索）

首页是整个知识库的入口，分为三个区域：

- **搜索框** — 粘贴 GitHub 仓库链接可快速发起导入，输入关键词则检索公开仓库
- **公开仓库** — 以树状或平铺方式浏览所有公开知识库
- **快捷操作** — 添加私人仓库、探索本周热门、MCP 接入说明

![登录后的首页](/images/home-loggedin.png)

左侧边栏分组：

| 分组 | 内容 |
| --- | --- |
| 发现 | 探索、推荐、机构目录 |
| 工作区 | 私有仓库、订阅、收藏夹、我的应用 |
| 工具 | MCP 服务 |

## 仓库文档页

点击任意仓库进入文档页，这是使用频率最高的页面：

![仓库文档页](/images/repo-docs.png)

| 区域 | 功能 |
| --- | --- |
| 分支选择器 | 在已生成文档的分支间切换 |
| 语言选择器 | 切换文档语言（取决于部署时 `WIKI_LANGUAGES` 配置） |
| 生成状态 | 显示该分支最新一次生成的状态与时间 |
| 项目架构 | 跳转到[思维导图](/docs/usage/mindmap) |
| 导出 SKILL | 把本仓库文档打包为 SKILL ZIP 下载 |
| 目录树 | 多级 Wiki 目录，点击切换章节 |
| 正文区 | 渲染 Markdown，含表格、代码高亮、Mermaid 图 |

右下角的**悬浮球**是仓库 AI 助手入口（需管理员在后台启用聊天助手并配置模型）：

![仓库内 AI 对话](/images/repo-chat.png)

对话时 AI 会自动携带"当前正在阅读的文档"作为上下文，也可以在面板中手动切换关联的目录章节。

## 个人设置

点击右上角头像进入个人设置，可修改昵称、头像、密码，以及界面语言偏好：

![个人设置](/images/user-settings.png)

## 界面语言切换

顶栏的语言图标可即时切换 UI 语言（简体中文 / English / 한국어 / 日本語 等 8 种）。切换结果保存在浏览器 Cookie 中，不影响文档生成语言。

<Callout type="info">
  UI 语言与文档语言是两回事：UI 语言只影响界面文案；文档语言由仓库生成时的配置决定，可在文档页左上角随时切换。
</Callout>

## 我的 MCP 服务

「工具 → MCP 服务」页面汇总了当前实例提供的 MCP 端点与接入说明，可直接复制配置片段到 Claude Desktop / Cursor：

![MCP 服务页面](/images/mcp-services.png)

详细接入步骤见 [MCP 集成](/docs/mcp)。

## 我的应用

「工作区 → 我的应用」管理嵌入式聊天应用（Chat App）：为单个仓库创建对话窗口、限制允许的域名、获取嵌入代码，把仓库知识库以聊天机器人形式挂到任意网站：

![我的应用](/images/my-apps.png)

创建与嵌入步骤见[分享与嵌入](/docs/usage/share-embed)。
