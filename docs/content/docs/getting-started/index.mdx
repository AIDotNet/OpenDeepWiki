# OpenDeepWiki 是什么

OpenDeepWiki 把 **Git 仓库、ZIP 压缩包、本地目录** 自动转换成一份可检索、可对话、可分享的**代码知识库**。你只需要提供一个仓库地址和一个 AI 模型的 API Key，剩下的——目录规划、文档撰写、多语言翻译、思维导图——全部由 AI 流水线完成。

## 解决什么问题

| 痛点 | OpenDeepWiki 的答案 |
| --- | --- |
| 接手陌生仓库无从下手 | 自动生成项目概览 + 层级 Wiki，配合思维导图快速建立全局认知 |
| 文档长期失修 | 仓库更新后可触发增量更新，文档跟随代码演进 |
| 团队知识口口相传 | 私有仓库知识库 + AI 对话，新人提问即可获得有出处的回答 |
| 外部用户看不懂开源项目 | 公开仓库 SEO 友好路由，让搜索引擎收录你的文档 |
| 工具链割裂 | MCP 服务让 Claude、Cursor 等工具直接查询仓库知识 |

## 系统组成

OpenDeepWiki 由两大部分组成：

- **后端 API（ASP.NET Core / .NET 10）**：仓库克隆与解析、AI 文档生成、翻译、思维导图、MCP 端点、后台 Worker 队列
- **前端站点（Next.js 16 / React 19）**：公共文档站、AI 对话、管理后台

数据层支持 **SQLite**（默认，零配置）与 **PostgreSQL**（生产推荐）。
