# 后台总览

使用管理员账号（默认 `admin@routin.ai`）登录后，通过左侧边栏进入**管理后台**：

![管理后台仪表盘](/images/admin-dashboard.png)

仪表盘汇总站点核心指标（用户数、仓库数、生成任务、Token 消耗等），是日常巡检的起点。

## 权限说明

- 内置角色：**Admin**（全部权限）与 **User**（前台功能）
- 只有 Admin 角色的用户可以访问 `/admin` 下的所有页面
- 部门（Department）用于组织架构归属，可配合"机构目录"与部门仓库使用

<Callout type="info">
  第一次进入后台建议先完成三件事：修改管理员密码（[用户管理](/docs/admin-guide/users-roles)）、核对模型配置（[AI Provider 与模型](/docs/admin-guide/ai-providers)）、浏览[系统设置](/docs/admin-guide/system-settings)。
</Callout>
