# 后台总览

使用管理员账号（默认 `admin@routin.ai`）登录后，通过左侧边栏进入**管理后台**：

![管理后台仪表盘](/images/admin-dashboard.png)

## 仪表盘

仪表盘是运营总览页，右上角可切换时间窗口（**7 天 / 14 天 / 30 天**）：

| 指标卡 | 含义 |
| --- | --- |
| 仓库提交 | 窗口内新导入的仓库数与"已处理"数量，附完成率 |
| 新增用户 | 窗口内新注册账号数 |
| Token 消耗 | 输入/输出/合计 Token 与**预估成本** |
| 缓存命中率 | AI 请求命中缓存的占比（衡量成本优化效果） |
| 仓库统计 / 用户增长 | 趋势图 |
| MCP 使用趋势 | 请求数、错误数与成功率 |

图表用于日常巡检：仓库提交涨但完成率掉 → 去仓库管理看失败原因；Token 消耗突增 → 检查是否有人批量重新生成。

## 侧边栏结构

- **概览**：仪表盘
- **内容管理**：仓库管理、GitHub Import
- **组织权限**：用户管理、角色管理、部门管理
- **AI 配置**：工具配置（MCPs 管理 / Skills 管理 / AI 服务商 / 模型管理 / 模型配置）、MCP 管理、对话助手配置、聊天平台配置

## 权限说明

- 内置角色：**Admin**（全部权限）与 **User**（前台功能），支持自定义角色
- 只有 Admin 角色的用户可以访问 `/admin` 下的所有页面
- `IsSystem` 标记的系统内置管理员不可删除，防止锁死管理入口

<Callout type="info">
  第一次进入后台建议按顺序完成：快速设置向导跑通 AI（[系统设置](/docs/admin-guide/system-settings)）→ 修改管理员密码（[用户管理](/docs/admin-guide/users-roles)）→ 浏览仪表盘确认数据。
</Callout>
