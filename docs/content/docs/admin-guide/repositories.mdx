# 仓库管理

路径：**管理后台 → 仓库管理**。这里是全站仓库的"任务中心"：

![仓库管理](/images/admin-repositories.png)

## 列表信息

每行显示仓库的来源（Git/ZIP/本地目录）、组织/名称、公开状态、生成状态与最近更新时间。生成状态包括：

| 状态 | 含义 |
| --- | --- |
| Pending | 已入队，等待 Worker |
| Processing | 正在扫描/生成 |
| Completed | 生成完成，文档可访问 |
| Failed | 生成失败，详情看处理日志 |

## 查看处理日志

点击仓库进入详情页（或点击行操作），可以看到**处理日志**：每次生成的阶段记录（克隆、扫描、目录生成、正文生成、翻译、思维导图）与错误信息。排障的第一入口。

## 重新生成

文档内容与代码不一致、或生成失败修复配置后，可以重新生成：

<Steps>

<Step>在列表勾选目标仓库（支持多选）。</Step>

<Step>点击**批量操作 → 重新生成**（或单行操作里的重新生成）。</Step>

<Step>确认后系统按全量方式重新执行"目录 → 正文 → 翻译 → 思维导图"流水线。</Step>

</Steps>

<Callout type="warn">
  重新生成会重新调用 AI（消耗 Token）。只想更新变更部分请使用[增量更新](/docs/advanced/incremental-updates)。
</Callout>

## 删除与批量删除

- 删除仓库会同时删除其文档数据（软删除），并清理对应工作区
- 支持勾选后**批量删除**
- 公开仓库删除后对外立即不可访问；路由被再次创建同名仓库时恢复

## 常见任务

| 任务 | 操作 |
| --- | --- |
| 用户反馈文档 404 | 查列表状态：Failed → 看日志修配置重试；Pending → 检查 Worker 是否存活 |
| 仓库想换分支重新生成 | 详情页调整分支后重新生成 |
| 清理无用仓库释放磁盘 | 批量删除（工作区随删除清理） |
| 确认 AI 配置是否生效 | 新增一个小仓库试生成，看日志中的模型调用 |
