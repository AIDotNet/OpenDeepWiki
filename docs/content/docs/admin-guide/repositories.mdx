# 仓库管理

路径：**管理后台 → 仓库管理**。这里是全站仓库的"任务中心"，分为**列表页**与**仓库详情页**两级。

## 列表页

![仓库管理列表](/images/admin-repositories.png)

### 筛选与状态

- 顶部搜索：按仓库名称、组织或来源位置模糊搜索
- 状态筛选：待处理（Pending）/ 处理中（Processing）/ 已完成（Completed）/ 失败（Failed）
- 列表列：仓库（组织/名称）、可见性（公开/私有）、状态、统计（Star/Fork/浏览）、创建时间、操作
- 列表上方有统计卡：**当前页完成率**（如"完成 8 / 10，处理中 1"）、公开仓库占比；存在失败仓库时提示"失败仓库 N，建议优先排查"

### 行内操作

点击行内**查看详情**进入[仓库详情页](#仓库详情页)；其他行内操作含删除（有确认弹窗，警告"将删除该仓库及其所有相关数据，且无法恢复"）。

### 批量操作

勾选多行后，工具栏出现三个批量按钮：

| 按钮 | 行为 | 确认提示 |
| --- | --- | --- |
| 批量同步统计 | 从 Git 远端刷新 Star/Fork 数（**仅 Git 仓库支持**，其他来源自动跳过） | 无 |
| 批量重新生成 | 清空现有文档并重新进入全量生成队列 | "已生成的文档内容将被覆盖，确定要继续吗？" |
| 批量删除 | 删除仓库及全部相关数据 | "此操作将删除选中的 N 个仓库及其所有相关数据，且无法恢复" |

<Callout type="warn">
  批量重新生成会对每个选中仓库重新调用 AI（消耗 Token）。只想更新变更部分请用详情页的**触发增量更新**。
</Callout>

## 仓库详情页

点击"查看详情"进入 `/{id}` 详情页——仓库文档的可视化管理控制台：

![仓库详情页](/images/admin-repository-detail.png)

### 头部操作卡

显示仓库标识（组织/名称）、来源类型 Badge（Git 仓库 / ZIP 压缩包 / 服务器目录）、来源位置与生成状态。操作按钮：

| 按钮 | 说明 |
| --- | --- |
| 刷新 | 重新拉取详情数据 |
| 同步统计 | 仅 Git 来源；从远端同步 Star/Fork |
| 触发增量更新 | 仅 Git 来源；提交一次增量任务（返回任务 ID） |
| 生成 Graphify | 为该仓库生成知识图谱产物 |
| 全量重新生成（红色） | 清空并重走全部生成流程，需二次确认 |

### 仓库概览卡

- 两条覆盖率进度条：**分支覆盖率**、**默认语言覆盖率**
- 六个指标卡：分支/语言 数量、文档/目录 数量、Star/Fork（非 Git 显示"不可用"）、每语言平均文档数、Graphify 状态（含完成时间）、Branch generation（生成任务状态，Idle/处理中，含任务 ID 与错误信息）

### 扫描策略配置卡

控制目录扫描的深度预算，**对该仓库所有分支生效**：

- 模式下拉：**自动评估（Auto）** / **手动配置（Manual）**
- Auto 模式：AI 按仓库规模自动评估，点击**重新评估**触发
- Manual 模式可手动设置：目录树最大深度、文件列表最大深度、最大目录树节点数、每目录最大文件数、最大总文件数、额外排除目录（逗号分隔，如 `build, temp, dist`）
- 右侧只读卡"生效的扫描策略（Resolved Plan）"显示策略来源、置信度百分比、评估原因与更新时间

### 分支 Tab

每个分支一张卡片：状态 Badge、最后提交、最后处理时间、生成任务状态与错误信息、语言列表（`语言 (文档数/目录数)`）。可对分支执行全量生成、重试、取消等待中任务，下方为分支生成任务表（Task/Branch/Status/Created/Retry/Actions）。

### 文档 Tab（在线编辑文档）

这是运营者最常用的页面：

1. 顶部筛选：选择**分支**和**语言**（默认语言带"（默认）"后缀）
2. 三个统计卡：已加载节点数、当前语言的文档/目录数、覆盖率
3. 左侧**文档树**（可折叠），右侧**文档内容**预览
4. 点击**编辑**进入编辑器（可修改 Markdown），按钮变为**保存**/**取消**；底部显示字数统计
5. **重新生成当前文档**：只重生成选中的这一篇（确认提示"将覆盖当前内容"），适合单篇质量不佳时快速重试
6. 有未保存修改时切换分支/语言/文档会提示"确定要放弃吗？"

### 日志 Tab（处理日志）

- 头部显示**当前步骤进度**（如"生成文档（3/9 文档）"）与进度条
- 四阶段流程卡：**准备工作区 → 构建目录 → 生成文档 → 归档并完成**，每步以颜色区分 完成/进行中/失败/等待中
- 日志表格（最近 200 条）：时间 / 步骤 / 类型（AI 或 系统）/ 范围（分支/任务）/ 消息
- 可按分支和 taskId 过滤，点**刷新日志**更新

### 增量更新 Tab

- 头部：**触发增量更新**按钮
- 三张统计卡：成功率、活跃率、失败告警
- 任务状态分布：总计 / 处理中 / 等待中 / 已完成 / 失败，配彩色分布条
- 任务表：任务 ID / 分支 / 状态 / 创建时间 / 重试次数 / 操作（刷新、重试——**仅失败任务可重试**）

## 常见任务速查

| 任务 | 操作路径 |
| --- | --- |
| 用户反馈某篇文档质量差 | 详情页 → 文档 Tab → 选中该篇 → 重新生成当前文档 |
| 文档小错别字想直接修 | 详情页 → 文档 Tab → 编辑 → 保存（不消耗 Token） |
| 仓库代码更新了 | 详情页 → 触发增量更新（省 Token）或全量重新生成（彻底） |
| 排查生成卡住 | 日志 Tab 看四阶段停在哪一步 + 具体错误消息 |
| Star 数不对 | 列表页勾选 → 批量同步统计 |
| 仓库扫描范围太大 | 详情页 → 扫描策略 → 手动配置降低深度/文件数预算 |
