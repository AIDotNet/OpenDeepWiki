# 聊天助手与聊天平台

本页包含两个相关但独立的功能：

1. **对话助手配置**：控制仓库文档页的 AI 悬浮球（站内）
2. **聊天平台配置**：把仓库知识库接入外部 IM（飞书 / QQ 机器人 / 微信客服 / Slack / 自定义）

## 对话助手配置

路径：**管理后台 → 对话助手配置**：

![聊天助手配置](/images/admin-chat-assistant.png)

| 配置项 | 说明 |
| --- | --- |
| 启用对话助手 | 开关；开启后文档页面显示对话助手悬浮球 |
| 可用模型 | 多选：选择助手可以使用的 AI 模型（来自[模型管理](/docs/admin-guide/ai-providers)中已启用的模型，显示上下文/能力标记） |
| 默认模型 | 用户打开对话面板时默认选中的模型 |
| 可用 MCPs | 多选：允许助手调用的 MCP 工具（来自 MCPs 管理） |
| 可用 Skills | 多选：允许助手使用的技能（来自 Skills 管理） |

配置后点**保存配置**，前端通过 `/api/v1/chat/config` 读取状态渲染悬浮球。

<Steps>

<Step>确认[AI 服务商](/docs/admin-guide/ai-providers)中已有已启用的服务商与模型（没有时页面会提示"暂无 AI 服务商"）。</Step>

<Step>打开**启用对话助手**开关。</Step>

<Step>勾选可用模型、指定默认模型；按需勾选 MCP 工具与技能。</Step>

<Step>保存后刷新仓库文档页，右下角出现悬浮球即为生效。</Step>

</Steps>

## 聊天平台配置

路径：**管理后台 → 聊天平台配置**。卡片列表显示各平台的显示名称、启用状态、注册状态、Webhook 地址、消息间隔与最大重试次数；每张卡片可重新加载、编辑、删除、启停。

![聊天平台配置](/images/admin-chat-providers.png)

### 新增平台

点击**新增平台**，表单分两部分：**通用字段** + 随平台动态渲染的**平台配置**。

通用字段：

| 字段 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| 平台 | 是 | 飞书 | 飞书 / QQ机器人 / 微信客服 / Slack / 自定义（编辑时锁定） |
| 显示名称 | 是 | | 界面展示名 |
| Webhook 地址 | 否 | | 平台回调入口 |
| 消息间隔 | 否 | 500（ms） | 两条回复之间的间隔，防止刷屏限流 |
| 最大重试次数 | 否 | 3 | 回复失败重试上限 |
| 启用 | 否 | 开 | |

## 常见问题

**悬浮球不出现**
助手未启用、未勾选模型，或浏览器缓存旧页面；用 `curl /api/v1/chat/config` 确认返回 `isEnabled: true`。

**平台卡片显示"未注册"**
平台侧回调未打通：检查 Webhook 地址、凭证是否填写完整、实例是否公网可达。

**IM 机器人不回复**
依次检查：回调地址 → 平台凭证 → 助手是否勾选模型；后端日志中有渠道错误详情。
