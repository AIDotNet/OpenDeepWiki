# 技能包与 MCP 管理

相关配置分布在管理后台三处，方向各不相同：

| 页面 | 路径 | 方向 |
| --- | --- | --- |
| Skills 管理 | 管理后台 → 工具配置 → Skills 管理 | 注入技能给 AI |
| MCPs 管理 | 管理后台 → 工具配置 → MCPs 管理 | 引入外部 MCP 工具给 AI 调用 |
| MCP 管理 | 管理后台 → MCP 管理 | 对外提供 MCP 服务（含调用日志与限流） |

## Skills 管理（Agent Skills）

遵循 **Agent Skills 开放标准**：每个 Skill 是一个包含 `SKILL.md` 的 ZIP 包，`SKILL.md` 必须含 `name` 与 `description` 字段。

![Skills 管理](/images/admin-skills.png)

- **上传 Skill**：点击右上角上传按钮，选择 ZIP（只支持 .zip，否则提示"只支持 ZIP 格式的压缩包"）
- **从磁盘刷新**：重新扫描服务器上的 Skills 目录
- 卡片信息：名称、版本、作者、许可证、兼容性、允许的工具、描述、启用状态
- 删除警示："将同时删除磁盘上的文件夹，此操作无法撤销"

上传的 Skill 可在[对话助手配置](/docs/admin-guide/chat-assistant)中勾选启用，让站内 AI 掌握该技能。

## MCPs 管理（外部 MCP 工具）

登记**外部** MCP 服务器，让 OpenDeepWiki 的 AI 在对话中调用这些工具：

点击**新增 MCP**，表单字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | MCP 标识 |
| 服务器地址 | 是 | MCP 端点 URL |
| API Key | 可选 | 目标服务要求的凭证 |
| 描述 | 可选 | |
| 启用 | 否 | 默认开 |
| 排序 | 否 | 控制在助手选择列表中的顺序 |

启用的 MCP 会出现在[对话助手配置](/docs/admin-guide/chat-assistant)的"可用 MCPs"多选列表中。

## MCP 管理（对外提供服务）

路径：**管理后台 → MCP 管理**。管理 OpenDeepWiki **对外暴露**的 MCP 提供商（OpenDeepWiki 自身的仓库知识服务就是一个内置提供商），页面分**提供商**与**调用日志**两个 Tab。

新增/编辑提供商的字段：

| 字段 | 说明 |
| --- | --- |
| 名称 / 描述 | 标识与说明 |
| 服务地址 | MCP 端点；有"固定全局 MCP 地址"提示——后端会根据问题自动路由仓库 |
| 传输方式 | Streamable HTTP / SSE |
| 绑定模型 | 可选；"不绑定模型"表示使用系统默认 |
| 需要用户 API Key | 开启后终端用户调用前需自行提供密钥；配套"API Key 获取地址"（指导用户去哪获取）与"系统 API Key"字段 |
| 每日请求上限 | 数字，可"不限"；用于限流 |
| 排序号 / 图标地址 / 启用此提供商 | 展示与启停 |

**调用日志 Tab**：时间 / 用户 / 工具 / 状态 / 耗时，合计"共 N 条"，配合仪表盘的 MCP 使用趋势排查调用量与错误率。

## 三者的关系

```
外部 MCP 服务（MCPs 管理）──调用──►  OpenDeepWiki AI
OpenDeepWiki AI          ──暴露──►  MCP 端点 /api/mcp（MCP 管理配置与审计）
Skill 包（Skills 管理）    ──注入──►  AI 能力/知识
```

| 需求 | 去哪配 |
| --- | --- |
| 让 AI 学会公司内部规范 | 上传 Skill 并在对话助手勾选 |
| 让 AI 对话中查外部系统（工单/数据库） | MCPs 管理登记外部 MCP |
| 给全公司 Agent 提供仓库知识、控制限流 | MCP 管理 |
