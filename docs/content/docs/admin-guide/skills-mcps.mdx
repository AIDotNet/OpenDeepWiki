# 技能包、MCP 工具与 MCP Provider

OpenDeepWiki 的 AI 不只靠提示词工作，还可以挂载**外部能力**：Skill 技能包与 MCP 工具服务。这三类配置都在**管理后台 → 工具**菜单下。

## 技能包（Skills）

路径：**管理后台 → 工具 → 技能包**：

![技能包管理](/images/admin-skills.png)

Skill 是一个 ZIP 包（含 `SKILL.md` 与资源文件），描述一项可复用的能力或知识。上传后可在聊天助手等场景启用，使 AI 掌握额外技能——比如"按公司规范写周报""用内部术语表翻译"。

上传要求：

- ZIP 内包含 `SKILL.md`（元数据与指令说明）
- 名称唯一，便于在启用列表中辨识

## MCP 工具

路径：**管理后台 → 工具 → MCP 工具**：

![MCP 工具](/images/admin-mcps.png)

登记**外部** MCP 服务器（工具服务），让 OpenDeepWiki 的 AI 在对话中调用这些工具（搜索、数据库查询、工单系统等）：

| 字段 | 说明 |
| --- | --- |
| 名称 | 工具服务标识 |
| 类型 / 端点 | 传输方式与服务地址（Streamable HTTP / SSE） |
| 认证 | 服务要求的凭证 |

在[聊天助手](/docs/admin-guide/chat-assistant)中勾选启用的 MCP 工具后，站内对话即可使用。

## MCP Provider

路径：**管理后台 → MCP Provider**：

![MCP Provider](/images/admin-mcp-providers.png)

与"MCP 工具"方向相反：MCP Provider 管理的是**对外提供** MCP 能力的元数据与用量统计。OpenDeepWiki 自身就是最重要的 MCP Provider——它把仓库知识通过 `/api/mcp` 暴露出去（接入方法见 [MCP 集成](/docs/mcp)），本页可查看调用统计与日常用量。

## 三者的关系

```
外部 MCP 服务（工具） ──调用──►  OpenDeepWiki AI
OpenDeepWiki AI   ──暴露──►  MCP 端点（/api/mcp）
Skill 包          ──注入──►  AI 能力/知识
```

| 配置 | 方向 | 典型用途 |
| --- | --- | --- |
| 技能包 | 注入能力 | 定制 AI 的领域知识与技能 |
| MCP 工具 | 引入外部工具 | 对话中查外部系统 |
| MCP Provider | 对外提供服务 | 把仓库知识供给全公司 Agent |
