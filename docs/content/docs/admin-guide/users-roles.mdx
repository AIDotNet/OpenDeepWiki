# 用户、角色与部门

## 用户管理

路径：**管理后台 → 用户管理**。

![用户管理](/images/admin-users.png)

### 列表与筛选

- 搜索框：按用户名或邮箱模糊搜索（输入即过滤）
- 角色筛选下拉：全部角色 / 各角色
- 列表列：用户、邮箱、角色（Badge）、状态（**下拉即改**：正常 / 禁用）、创建时间、操作

### 新增用户

点击右上角**新增用户**，弹窗含三个必填字段：

| 字段 | 说明 |
| --- | --- |
| 用户名 * | 登录显示名 |
| 邮箱 * | 登录凭证 |
| 密码 * | 初始密码 |

![新增用户弹窗](/images/admin-user-create.png)

<Callout type="info">
  新增用户弹窗里**没有**角色字段——创建后通过行内"分配角色"单独授予。
</Callout>

### 行内操作

| 操作 | 行为 |
| --- | --- |
| 分配角色 | 弹窗"分配角色 - 用户名"，勾选角色（来自角色管理的全部角色，显示名称+描述），默认勾选现有角色，点**保存** |
| 重置密码 | 弹窗"重置密码 - 用户名"，输入新密码 → **确认重置** |
| 删除 | 红色图标；确认弹窗警告"此操作将删除该用户及其所有相关数据，且无法恢复" |

状态列直接下拉切换**正常/禁用**，禁用后该账号无法登录。

## 角色管理

路径：**管理后台 → 角色管理**。内置 `Admin` 与 `User` 两个系统角色（带"系统角色" Badge，**不可编辑、不可删除**）。

- **新增角色**：弹窗两个字段——角色名称（必填）、描述（选填）
- 卡片显示：名称、描述、"N 个用户"、创建时间
- 删除确认提示："删除角色后，拥有该角色的用户将失去相应权限"

## 部门管理

路径：**管理后台 → 部门管理**。页面为**左右布局**：左侧"部门结构"树（节点带启用/禁用 Badge 与编辑/删除图标），右侧为选中部门的详情卡。

### 新增/编辑部门

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 部门名称 | 是 | |
| 上级部门 | 否 | 下拉显示缩进的部门树，"无"为顶级；编辑时排除自身（不能把自己挂到后代下） |
| 描述 | 否 | |
| 排序号 | 否 | 默认 0，控制同级显示顺序 |
| 启用状态 | 否 | 默认启用 |

删除警示："删除部门后不可恢复，如果该部门下有子部门则无法删除。"

### 部门详情：用户与仓库

右侧详情卡有两个 Tab：

- **用户 (n)**：点**添加用户** → 搜索用户名或邮箱 → 单选 → 可勾选**"设为部门主管"** → **添加**
- **仓库 (n)**：点**分配仓库** → 搜索仓库名 → 单选 → **分配**

被分配的仓库归部门所有，会出现在前台"机构目录"中按组织浏览。

## 典型实践

| 场景 | 配置方式 |
| --- | --- |
| 团队知识库统一入口 | 建立部门树 → 添加用户到部门 → 仓库 Tab 分配仓库给部门 |
| 细分权限 | 新建自定义角色 → 用户管理里"分配角色"勾选 |
| 员工离职 | 禁用账号（保留数据审计）或删除（级联清理其数据） |
| 密码遗忘 | 行内"重置密码"直接设置新密码 |
